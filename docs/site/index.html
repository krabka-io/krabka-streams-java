00Install

// build.gradle.kts — each module ships separately; any one pins the Kafka Streams API
implementation("io.krabka:krabka-streams:@VERSION@")
implementation("io.krabka:krabka-streams-schema-serde:@VERSION@")
implementation("io.krabka:krabka-streams-columnar:@VERSION@")
implementation("io.krabka:krabka-streams-columnar-schema:@VERSION@")
testImplementation("io.krabka:krabka-streams-test-utils:@VERSION@")

Or import io.krabka:krabka-streams-bom for version constraints across every module.

02The batch model

consumer.poll() ──▶ BatchCodec.decode ──▶ operators × Arrow ──▶ BatchCodec.encode ──▶ producer.send()

One fetched topic-partition batch is one processing unit: decoded into a single VectorSchemaRoot, transformed as whole batches by built-in or custom operators, produced and committed by the runner only after every acknowledgement arrives.
