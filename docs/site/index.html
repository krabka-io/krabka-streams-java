02The batch model

consumer.poll() ──▶ BatchCodec.decode ──▶ operators × Arrow ──▶ BatchCodec.encode ──▶ producer.send()

One fetched topic-partition batch is one processing unit: decoded into a single VectorSchemaRoot, transformed as whole batches by built-in or custom operators, produced and committed by the runner only after every acknowledgement arrives.
