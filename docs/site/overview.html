krabka streams for Java is the Java client library for stream processing with krabka. It exports the Apache Kafka Streams API unchanged and adds krabka schema registry serdes and Apache Arrow columnar batch processing.

The API is split across four artifacts, one per package group below. Each artifact depends on io.krabka:krabka-streams, so any one of them pins the Kafka Streams API version. See the guides for configuration, broker requirements, and worked examples.
